This is the **public asset library** for our Apify Actors. Store banners, screenshots, diagrams, and guide images here so they can be linked directly from Actor READMEs on the Apify Store.

Images are served via GitHub raw URLs — no hosting setup required.

## Featured Actors

Hand-picked tools from the [Apify Store profile](https://apify.com/johnvc?fpr=9n7kx3). Pay-per-use pricing, no subscriptions.

### ✈️ [Google Flights API](https://apify.com/johnvc/Google-Flights-Data-Scraper-Flight-and-Price-Search?fpr=9n7kx3)

Search one-way, round-trip, and multi-city itineraries. Filter by price, stops, airlines, and passenger counts. Supports 29+ languages and 39+ countries — built for travel apps and price monitoring.

### 🎭 [Google Events API](https://apify.com/johnvc/google-events-api---access-google-events-data?fpr=9n7kx3)

Extract concerts, conferences, festivals, sports, and theater from Google Events. Dates, venues, ticket links, and location filters included. MCP-ready for AI agents.

### 💬 [Google Forums API](https://apify.com/johnvc/google-forums-search-api?fpr=9n7kx3)

Scrape forum threads and Q&A from Google's Forums tab — Reddit, Quora, LinkedIn, and niche communities. Structured JSON for sentiment analysis and research.

### 📰 [Google News API](https://apify.com/johnvc/GoogleNewsAPI?fpr=9n7kx3)

Location-based news search with language filters and pagination. Returns titles, links, sources, snippets, and publication dates.

## Why these Actors?

- **Production-ready defaults** — retries, timeouts, sensible concurrency out of the box
- **Clear input schemas** — documented fields with example outputs
- **Pay per use** — no monthly rentals or surprise subscriptions
- **>99% run success rate** across 6,000+ users
- **Fast issue response** — typically within ~2 days

Built for developers who need data that actually lands in a pipeline, not a demo that breaks on page two.

## Using assets in Apify READMEs

1. Add your image to the appropriate folder under `assets/`.
2. Commit and push to `main`.
3. Reference it in your Actor README with a raw GitHub URL:

```markdown
![Setup guide](https://raw.githubusercontent.com/johnisanerd/ApifyPublicData/main/assets/guides/my-actor/step-1.png)
```

Tip: use `main` in the URL path so links stay stable after you tag releases.
